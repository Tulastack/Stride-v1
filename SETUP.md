# Stride Launch - Getting Started

This repository contains the backend API, Machine Learning Worker, and the Mobile Frontend for the Stride Launch application.

## Prerequisites
- **Docker** and **Docker Compose**
- **Node.js** (v18+)
- **Expo Go** app installed on your iPhone

## 1. Start the Backend Infrastructure
The backend uses Docker to run the API, ML Worker, Postgres Database, and LocalStack (AWS S3 & SQS emulator).

```bash
cd infra
docker compose down
docker compose up -d
```

**Note:** If you see `infra-localstack-init-1` hanging on "Waiting", it is likely just downloading the `amazon/aws-cli` image in the background. It will start successfully once the download finishes. We have verified that the containers are healthy.

## 2. Check the ML Worker Status (Optional)
Because you are on a very new Python version (Python 3.14), installing TensorFlow locally via `pip` will fail since wheels are not yet available. You do not need to run it locally; the Docker container handles it perfectly.

To verify the ML Worker is running:
```bash
docker logs infra-ml-worker-1
```
You should see `[Heartbeat] Polling SQS for jobs...` in the logs.

## 3. Run the Frontend (Mobile/Web)
We have updated your dependencies and fixed the `babel-preset-expo` and SDK mismatch errors.

```bash
cd apps/mobile
npm install
npm run start
```
- Press **i** to open the iOS simulator, OR
- Scan the QR code with your iPhone's camera to open it in **Expo Go**.
- Press **w** to open it on the web.

## AWS Integration
The frontend securely uploads videos to our LocalStack S3 bucket via presigned URLs generated by the API, and the API drops messages into the SQS queue, which the ML Worker polls.
